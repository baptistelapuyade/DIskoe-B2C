# Technische Entscheidungen

Dieser Ordner enthält datierte, nachvollziehbare technische Entscheidungen. Produktentscheidungen und Scope bleiben in Notion; hier werden technische Konsequenzen, geprüfte Optionen und Implementierungsbelege festgehalten.

## Dateiformat

`YYYY-MM-DD-kurzer-titel.md`

Jede Entscheidung enthält mindestens:

- Status: Vorgeschlagen, Angenommen, Ersetzt oder Verworfen;
- Kontext und betroffene bestätigte Produktregeln;
- betrachtete Optionen und relevante Trade-offs;
- Entscheidung und Begründung;
- Konsequenzen, Risiken und offene Nachweise;
- Datum, Entscheider und Links auf Quellen/Belege;
- ersetzte oder nachfolgende Entscheidung, falls zutreffend.

Eine vorgeschlagene ADR ist keine Freigabe. Implementierung und Laufzeitprüfung werden nur mit konkreten Commits, Tests oder Betriebsbelegen behauptet.
